# Cône Run

Endless runner montréalais. Trois voies, barils de balisage orange, nids-de-poule, échafauds.

- Moteur, collisions, personnage: `src/game/engine.ts`
- Musique et bruit de chute: `src/game/audio.ts`
- Rue et décors: `src/game/landmarks.ts`, `src/game/textures.ts`
- HUD: `src/components/cone-run.tsx`

```bash
npm install
npm run dev
```
